# 計分頁全螢幕計分 — 設計文件

日期：2026-08-25
狀態：已核准，待寫實作計畫

## 背景

觀眾頁已經有「全螢幕放大」功能（唯讀，只顯示比分），管理者計分頁想要一樣的全螢幕模式，但要能**直接在全螢幕畫面上計分**。

## 設計

**新增檔案** `src/components/admin/fullscreen-score.tsx`，沿用觀眾頁 `viewer/fullscreen-match.tsx` 已經驗證過的技術做法（原生 Fullscreen API + iOS 不支援時的純 CSS 覆蓋層 fallback、窄螢幕響應式版面、退出全螢幕不閃爍的 `close()` 處理），但這次是**可互動**版本：

- `ScoreRow`（`section-scoring.tsx`）的徽章列加一顆「⛶ 全螢幕計分」觸發按鈕。不管比賽狀態（未開賽／進行中／已完成）都顯示，讓工作人員可以先開好全螢幕再開賽，或事後用全螢幕修正分數。
- 全螢幕畫面維持觀眾頁那種左右分色（左深藍、右深紅），各自顯示隊伍名稱＋大比分數字。
- **點那一半螢幕的任何地方（不只是小按鈕）都會 +1**——手速快、不用精準瞄準小目標。
- 每一半各自疊一組半透明的 `+`／`−` 圓形按鈕：
  - `−` 只能透過這顆按鈕觸發（避免誤觸整面螢幕不小心扣分）。
  - `+` 按鈕效果跟點整面螢幕一樣，多一個精準的選項（按鈕本身要 `stopPropagation`，不然會跟整面點擊疊加變成 +2）。
- 直接重用 `ScoreRow` 既有的 `bump(side, delta)` 函式（已經包含這次 session 修過的「網路失敗不亂 revert」邏輯），全螢幕元件只負責 UI、不重寫計分邏輯——`FullscreenScoreButton` 收 `onBump` callback，`ScoreRow` 直接把自己的 `bump` 傳進去。

## 範圍

- 只在管理者計分頁加這個功能，觀眾頁的唯讀全螢幕（`fullscreen-match.tsx`）不受影響、不共用元件（一個唯讀、一個可計分，職責不同，各自獨立檔案，沿用這個專案「小工具各檔案各自定義」的慣例）。
- 不額外做「鎖定方向」「防呆二次確認」之類的進階功能，先做最直接的版本。

## 測試

純 UI 元件，這個專案沒有元件測試基礎設施，靠人工驗證（沿用觀眾頁全螢幕功能當時的做法）。
